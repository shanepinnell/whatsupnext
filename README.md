# WhatsUpNext

A conference room display for Apple TV.

Walk up and instantly see whether the room's free, what's coming up next,
and who's in the current meeting — no more guessing or double-booking.
WhatsUpNext plugs into whatever calendar system you already use (Google,
Microsoft, or any ICS feed), and can also act as a supplementary display
for building emergency notifications (lockdown alerts, etc.), integrating
with systems like Singlewire InformaCast.

It's built to actually keep working: the display caches its own data and
keeps functioning even if the backend goes down, and setup scales from
"read a pairing code off the screen" for a single room to fully
zero-touch provisioning via MDM for a whole building.

You're not locked into a subscription to get it — buy it once and
self-host it forever (you own the code, no ongoing dependency on us), or
let us host and manage it for you if you'd rather not run the
infrastructure yourself, at [whatsupnext.io](https://whatsupnext.io).
